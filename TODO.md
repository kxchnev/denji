## Идея

Библиотека + CLI для диаграмм (аналог mermaid.js), исправляющая главную боль
mermaid — **невозможность управлять положением элементов**. Здесь layout
управляемый. Типы диаграмм: **flowchart** и **sequence**.

## Ключевые решения

| Решение | Выбор |
|---|---|
| Стек | **TypeScript** — npm-библиотека + CLI (Node), рендер в SVG |
| Управление layout | **Гибрид**: авто-раскладка по умолчанию + пины/хинты (`pin`, `rightOf`, `below`, `sameRank`, `gap`) как constraints |
| Ввод | **DSL + API**; архитектурно API/модель — ядро, DSL парсится в ту же модель |

## Архитектура (слои)

```
DSL (текст) ──parse──► Model (IR + builder API) ──layout──► Geometry ──render──► SVG
                            ▲                        ▲
                       пины/хинты               ядро отличия от mermaid
```

1. **Model / IR** — `src/model/` — типы + fluent-билдер.
2. **DSL parser** — `src/dsl/` — текст → Model.
3. **Layout engine** — `src/layout/` — Model + constraints → координаты.
4. **Renderer** — `src/render/` — геометрия → SVG (без зависимостей).
5. **CLI** — `src/cli.ts` — `.diagram` файл → `.svg`.

- [x] Слоистая раскладка (`src/layout/layered/`): rank → order → position, как dagre
- [x] Удаление циклов (DFS-разворот back-рёбер), longest-path ранжирование

- [x] Пин = escape hatch: узел в абсолютную точку, вне авто-потока
- [x] Dummy-узлы на длинных рёбрах + ортогональный роутинг (`route.ts`)
- [x] Трансформация координат под TB/BT/LR/RL
- [x] Тесты (`test/layout.test.ts`): ранги, sameRank, rightOf, наложения, детерминизм, цикл, пин
- [x] Примеры `examples/basic.ts` (пин) и `examples/complex.ts` (ветвление+слияние+цикл+хинты), проверены растеризацией

Известные упрощения (кандидаты на доработку):
- Координаты — barycenter + устранение наложений (не Brandes-Köpf); длинные рёбра могут слегка вилять
- Пин не резервирует место (по решению) — может наложиться, если пиннуть в гущу
- Роутинг без полного обхода препятствий; overlapping параллельные рёбра не разводятся
