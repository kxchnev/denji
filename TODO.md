## Идея

Библиотека + CLI для диаграмм (аналог mermaid.js), исправляющая главную боль
mermaid — **невозможность управлять положением элементов**. Здесь layout
управляемый. Типы диаграмм: **flowchart** и **sequence**.

## Ключевые решения

| Решение | Выбор |
|---|---|
| Стек | **TypeScript** — npm-библиотека + CLI (Node), рендер в SVG |
| Управление layout | **Гибрид**: авто-раскладка по умолчанию + пины/хинты (`pin`, `rightOf`, `below`, `sameRank`, `gap`) как constraints |
| Ввод | **DSL + API**; архитектурно API/модель — ядро, DSL парсится в ту же модель |

## Архитектура (слои)

```
DSL (текст) ──parse──► Model (IR + builder API) ──layout──► Geometry ──render──► SVG
                            ▲                        ▲
                       пины/хинты               ядро отличия от mermaid
```

1. **Model / IR** — `src/model/` — типы + fluent-билдер.
2. **DSL parser** — `src/dsl/` — текст → Model.
3. **Layout engine** — `src/layout/` — Model + constraints → координаты.
4. **Renderer** — `src/render/` — геометрия → SVG (без зависимостей).
5. **CLI** — `src/cli.ts` — `.diagram` файл → `.svg`.
